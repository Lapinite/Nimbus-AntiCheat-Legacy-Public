# Nimbus AntiCheat Legacy

**Official public distribution repository for Nimbus AntiCheat Legacy.**

Nimbus AntiCheat is the free-to-use proprietary anti-cheat product by the Leviathan Project. This repository is intentionally public so server owners can find official releases, checksums, documentation, compatibility information, support guidance, and security information without exposing the private source code.

## Product line

- **Legacy line:** Minecraft 1.8.8 through the pre-1.21 compatibility line.
- **Modern line:** Minecraft 1.21.x and current supported releases are distributed separately from `Nimbus-AntiCheat-Modern-Public`.
- **Price:** Free to use under the included proprietary license.
- **Source:** Closed source. The private development repository is not mirrored here.

## Downloads

Official compiled releases will be published through this repository's **Releases** page after the applicable release gates pass.

Do not download Nimbus AntiCheat from unofficial mirrors.

## Release verification

Official releases include a SHA-256 checksum file next to the JAR. Verify the checksum before installing a release.

## Compatibility

The Legacy line begins at Minecraft 1.8.8 and covers the pre-1.21 compatibility range. Java and server-platform requirements may vary by supported Minecraft family and will be documented with each release.

See `docs/COMPATIBILITY.md`.

## Safety

Nimbus uses conservative defaults during development and release-candidate testing. Automatic enforcement is not enabled merely because a detector exists. New checks require calibration, false-positive review, performance review, and compatibility validation before they can be trusted for punitive actions.
