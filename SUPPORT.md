# Support

This repository is the official public distribution repository for Nimbus AntiCheat Legacy.

## Before requesting help

Please provide:

- Nimbus version;
- Minecraft version;
- server software and exact build;
- Java version;
- relevant dependency versions;
- relevant Nimbus configuration;
- complete relevant error messages or stack traces;
- steps that reproduce the problem.

Remove passwords, tokens, private keys, database credentials, player personal data, and other secrets before posting logs.

## Where to report

Use this repository's **Issues** area for reproducible non-sensitive bugs and release problems when Issues are enabled.

Security-sensitive reports must follow `SECURITY.md` and should not be posted publicly.

## Scope

The Legacy line begins with Minecraft 1.8.8 and covers the pre-1.21 compatibility range. Problems on Minecraft 1.21.x and current supported versions belong to the Nimbus AntiCheat Modern product line.
