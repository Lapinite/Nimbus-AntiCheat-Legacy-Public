# Compatibility

## Product boundary

Nimbus AntiCheat Legacy begins at Minecraft 1.8.8 and covers the pre-1.21 compatibility range.

Minecraft 1.21.x and current supported releases belong to Nimbus AntiCheat Modern.

## Server platforms

The Legacy line is intended for compatible Bukkit, Spigot, and Paper-family server implementations where the specific Minecraft version is supported.

A platform or Minecraft version is not considered supported merely because the plugin starts. Support is claimed only after the applicable startup, movement, combat, packet, teleport, respawn, velocity, world/chunk, performance, security, and false-positive regression gates pass.

## Java

Java requirements vary across the Legacy Minecraft range. Release notes will state the Java requirement for each published artifact.

The 1.8.8 compatibility target uses Java 8 bytecode.

## Dependencies

Some releases may require or optionally integrate with external plugins such as packet providers or moderation systems. Required and optional dependencies will be stated in the release notes.

## Release candidates

Release candidates are test builds and may have incomplete compatibility coverage. Do not treat an RC as a final production release unless the release notes explicitly state otherwise.
